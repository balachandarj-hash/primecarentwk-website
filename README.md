# PrimeCare Network — Website Redesign

Static redesign prototype repositioning PrimeCare Network around three pillars:

1. **Providers Network**
2. **Care Coordination**
3. **Legal Nurse Case Manager**

Brand teal / navy colors are preserved. Financing is retained as supporting capability, not the lead message.

## Preview

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Brand-first home + three pillars |
| `providers-network.html` | Network partnership & lien support |
| `care-coordination.html` | Concierge coordination |
| `legal-nurse-case-manager.html` | LNC / nurse advocacy |
| `about.html` | Company narrative |
| `contact.html` | Partner intake form (prototype) |
